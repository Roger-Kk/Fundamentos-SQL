# 🗄️ Fundamentos SQL

Repositório dedicado aos meus estudos de **SQL e Banco de Dados**, com exercícios práticos desenvolvidos durante minha formação em desenvolvimento de software.

Os conteúdos estão organizados em uma sequência de estudos, começando pelos fundamentos de bancos relacionais e operações CRUD e avançando para consultas, funções, `JOINs`, subconsultas, views, procedures, transactions, triggers e backup.

> Os exercícios foram desenvolvidos durante meus estudos na **Alura**, utilizando principalmente conceitos e recursos de SQL praticados ao longo dos cursos.

---

## 🎯 Objetivo

Construir uma base sólida em SQL, praticando desde a criação e manipulação de estruturas de banco de dados até recursos mais avançados de programação SQL.

A organização dos arquivos representa a evolução dos estudos:

Fundamentos
    ↓
CRUD e estrutura de tabelas
    ↓
Consultas e operações
    ↓
JOINs e subconsultas
    ↓
Funções e filtros
    ↓
Programação SQL
    ↓
Procedures, Transactions e Triggers
    ↓
Backup
