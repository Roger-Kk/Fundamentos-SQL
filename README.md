# Fundamentos SQL

Repositório dedicado aos meus estudos de **SQL e Banco de Dados**, com exercícios práticos desenvolvidos durante minha formação em desenvolvimento de software.

Os conteúdos estão organizados em uma sequência de estudos, começando pelos fundamentos de bancos relacionais e operações CRUD e avançando para consultas, funções, `JOINs`, subconsultas, views, procedures, transactions, triggers e backup.

## Fundamentos de banco de dados

* [CREATE / DROP DATABASE](./01_CREATE-DROP-DATABASE.sql) — criação e exclusão de bancos de dados.
* [CREATE TABLE](./01_CREATE%20TABLE.sql) — criação e estruturação de tabelas.
* [ALTER TABLE](./01_ALTER-TABLE.sql) — alteração da estrutura de tabelas.
* [PRIMARY KEY](./01_PRIMARYKEY.sql) — criação e utilização de chaves primárias.

### Manipulação de dados — CRUD

* [INSERT](./01_INSERT.sql) — inserção de registros nas tabelas.
* [SELECT](./01_SELECT.sql) — consultas e seleção de dados.
* [UPDATE](./01_UPDATE.sql) — atualização de registros.
* [DELETE](./01_DELETE.sql) — exclusão de registros.

## Consultas e recursos SQL

* [SELECT](./02_SELECT.sql) — consultas e seleção de informações.
* [Operações](./02_OPERACOES.sql) — operações utilizadas nas consultas SQL.
* [CASE](./02_CASE.sql) — utilização de CASE para criação de condições nas consultas.
* [JOIN](./02_JOIN.sql) — combinação de dados entre tabelas utilizando JOIN.
* [UNION](./02_UNION.sql) — combinação de resultados de consultas utilizando UNION.
* [Subconsultas e VIEW](./02_SUBCONSULTA-VIEW.sql)  — subconsultas e criação/utilização de VIEW.
* [Funções](./02_FUNCOES.sql) — utilização de funções em consultas SQL.

## Filtros

* [Filtros](./03_FILTROS.sql) — aplicação de filtros para restringir os resultados das consultas.

## Programação SQL

* [Criando Funções](./04_CRIANDO_FUNCOES) — criação de funções dentro do banco de dados.
* [IF](./04_IF) — estruturas condicionais utilizando IF.
* [Procedures](./04_PROCEDURES) — criação e utilização de procedures.
* [Transactions](./04_TRANSACTION) — utilização de transactions para controle de operações.
* [Triggers](./04_TRIGGERS) — criação e utilização de triggers.
* [WHILE / DO](./04_WHILE_DO) — estruturas de repetição utilizando WHILE e DO.

## Backup

* [Backup](./05_BACKUP)  — práticas relacionadas a backup de banco de dados.

# Como rodar

Os arquivos .sql devem ser executados em um sistema gerenciador de banco de dados compatível com SQL.

A sequência recomendada para os estudos segue a organização numérica dos arquivos:

01_ → Fundamentos e operações básicas

02_ → Consultas e recursos SQL

03_ → Filtros

04_ → Programação SQL

05_ → Backup
